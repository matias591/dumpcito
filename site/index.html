What it does

Quiet until it matters.

No dashboards, no notification pile. One small character that reacts to three real things.

Knows when Claude is waiting

A permission prompt, a question, or a finished session. Connect Claude Code once and it reacts to the real event, not a guess.

Nudges you before meetings

Reads the Mac Calendar app, so Google, iCloud and Outlook calendars all work. One tap joins the call.

Hold a key and talk

Say what you need while it grabs a screenshot, then send both to Claude Code. Speech is recognised on your Mac.

Never lose it

It follows you, and stays clickable.

Move to another display and the buddy hops over. When it needs you it glides to your cursor on a spring, and the moment you reach for it, it holds still so you can click.

How it works

Three minutes, start to finish.

Install it

Download, drag to Applications, open. macOS will ask once because the app is not yet signed with an Apple Developer ID. The steps are below.

Take the short tour

Pick a look, connect Claude Code, and allow only what you want: calendar, microphone, screen recording. Every step can be skipped.

Go back to work

Right-click the buddy any time to switch skins, mute sounds or pause nudges. It stays out of the way until something needs you.

Install

Get Dumpcito for Mac.

Requires macOS 14 or later, Apple Silicon or Intel. Free, MIT licensed.

Download the latest releaseView the source

Verify and move it

Unzip, then check the download matches the checksum on the release page.

shasum -a 256 Dumpcito.zip

Then drag Dumpcito.app to your Applications folder.

Open it past the warning

Open the app. macOS says it cannot verify it. Go to System Settings, Privacy & Security, scroll down, click Open Anyway and confirm. Prefer Terminal?

xattr -dr com.apple.quarantine /Applications/Dumpcito.app

Allow screen recording once

Only needed for hold-to-talk screenshots. Allow it in System Settings, then quit and reopen the app. macOS does not apply it until then.

Why the warning? Apple charges for the signing certificate that removes it. The whole project is open, so you can read the code or build it yourself before you run it.

Privacy and safety

Small enough to audit.

No network code

The app has no networking at all. Speech recognition runs on your Mac and never falls back to a server.

Owner-only files

Everything it writes is readable only by you. Screenshots are deleted after 24 hours.

Nothing is sent for you

Prompts come from what you say or type. New sessions open pre-filled and wait for you to press Enter.

Easy to remove

Disconnect Claude Code from the menu and the hook is removed, with a backup of your settings kept.

One thing to know: a screenshot you send to an agent with shell access can be read by that agent, so treat text on screen as input it will see.

Questions

Quick answers.

Which agents work?

Claude Code (terminal, VS Code, Desktop Code tab) and Codex get “needs you” and “finished” alerts. Cursor gets “finished” only. Claude Desktop chat and ChatGPT desktop have no hooks, so they are not supported. The tour connects each one with a live check.

Which calendars work?

Any calendar your Mac already has. For Google Calendar, add the account in System Settings, Internet Accounts, with Calendars switched on.

Can I send a prompt into a session that is already open?

That needs a small companion plugin for Claude Code, which is not part of this release. Without it, hold-to-talk opens a new Claude Code session in VS Code with your prompt filled in.

How do I make it quiet?

Right-click the buddy: mute sounds, or pause nudges to stop all alerts and chasing.

Is it affiliated with Anthropic?

No. It is an independent open-source project that works alongside Claude Code.
